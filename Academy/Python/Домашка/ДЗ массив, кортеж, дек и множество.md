~={blue}Задача:=~ Создать два списка, которые наполняются пятью случайными целыми числами от 0 до 10 с помощью ~={cyan}random=~.
~={orange}Например:=~ [5, 8, 5, 3, 5] и [5, 5, 8, 5, 4]
~={green}Необходимо:=~
1. Сформировать ~={red}дек=~, содержащий элементы 1 и 2 списка. Затем в начале и в конце добавить число 1.
	~={orange}Пример:=~ ([1, 5, 8, 5, 3, 5, 5, 5, 8, 5, 4, 1])
2. Сформировать ~={red}множество=~, содержащее элементы 1 и 2 списка без повторений;
	~={orange}Пример:=~ {8, 3, 4, 5}
3. Сформировать ~={red}массив=~, содержащий элементы общие для 1 и 2 списка;
	~={orange}Пример:=~ [8, 5]
4. Сформировать ~={red}список=~, содержащий только уникальные элементы 1 списка и уникальные элементы 2 списка;
	~={orange}Пример:=~ [8, 3, 5, 8, 4, 5]
5. Сформировать ~={red}кортеж=~, содержащий только минимальное и максимальное значение каждого из списков.
	~={orange}Пример:=~ [3, 8, 4, 8] Пользователь ничего не вводит, он только получает результат.

Каждый пункт и изначальные списки вывести на экран, чтобы пользователю было понятно.
